# e361 — Le forme nuove sono due parole attaccate?

Preregistrazione: `preregistrazioni/e361.md`.

- Forme nuove (≥ 5 segni): 3090; si tagliano in due parole esistenti: 0.487.
- Errori (≥ 5 segni): 0.443.
- Parole comuni della stessa lunghezza: 0.762 (z della differenza -39.3).
- Fra le forme nuove attaccate, la coppia compare altrove come due parole vicine: 0.162 (fondo con le parti accoppiate a caso 0.089).
- In fine riga: attaccate 0.223, altre forme nuove 0.178.

Esito: **no**.

Esempi: syaiir = sy + aiir, cthoary = ctho + ary, roloty = ro + loty, shodary = sho + dary, shodan = sho + dan, kodshey = ko + dshey, shokcheey = sho + kcheey, pydeey = py + deey, ydoin = yd + oin, ctholdar = ctho + ldar, okodar = ok + odar, kotchody = ko + tchody.
