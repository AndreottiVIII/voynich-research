# e189 — Capacità massima di tre canali "liberi"

Preregistrazione: `preregistrazioni/e189.md`.

| canale | bit |
|---|---|
| (a) scelte di grafia (e182) | 49215 |
| (b) segno d'inizio riga | 5823 (1.75 per riga, 3332 righe) |
| (c) ordine delle parole nella riga | 40137 (esatti 7066 su 1387 righe; 1.34 bit per parola nelle righe di 6–7) |
| **totale** | **95175** |

Equivalente: 23213–47588 lettere di latino, cioè 3869–7931 parole (grezzo–compresso).
